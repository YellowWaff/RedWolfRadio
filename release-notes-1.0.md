# Red Wolf Radio 1.0.0

- Play external RIFF XWMA/WMAudio2 files through the game's native music loader without converting them to WAV. Long and Unicode paths use unchanged compressed cache copies.
- Open a compact, movable music player from **Settings → Other → Scripts → Red Wolf Radio**. Its filename refreshes automatically; icon buttons provide Previous, Restart, Play/Pause and Next, with action names on hover.
- Use English or Russian instructions, INI help and player messages. Set `[Display] Language=ru` for Russian hover descriptions. Source filenames retain their original spelling.
- The player is enabled by default. The separate five-second track notification is optional and off by default (`ShowTrackName=false`). Existing explicit INI preferences are preserved.

Requires Windows x64, WRSR 1.1.1.9 and Republic Mod Loader 1.0.1. XWMA support is limited to the validated WMAudio2 profile: mono/stereo, 16-bit decoded samples, 8–48 kHz. WAV, MP3 and FLAC support, configurable shortcuts and cache limits remain available. No music is included; original game files are preserved.

## Русский

- Внешние RIFF XWMA/WMAudio2 воспроизводятся игровым загрузчиком без преобразования в WAV. Для длинных путей и кириллицы используется неизменённая сжатая копия в кэше.
- Компактный перемещаемый плеер доступен через **Настройки → Другое → Сценарии → Red Wolf Radio**. Название трека обновляется автоматически; кнопки-значки: «Предыдущая», «Сначала», «Играть/Пауза» и «Следующая». Название действия появляется при наведении.
- Инструкции, комментарии INI и сообщения плеера доступны на английском и русском. Для русских подсказок задайте `[Display] Language=ru`. Имена файлов не переводятся.
- Плеер включён по умолчанию. Отдельное пятисекундное уведомление по умолчанию отключено (`ShowTrackName=false`). Явно заданные настройки существующего INI сохраняются.

Требуются Windows x64, WRSR 1.1.1.9 и Republic Mod Loader 1.0.1. Поддерживается проверенный профиль WMAudio2: один или два канала, 16-битные декодированные отсчёты, 8–48 кГц. Поддержка WAV, MP3 и FLAC, настраиваемые сочетания клавиш и лимит кэша сохранены. Музыка не входит в комплект; оригинальные файлы игры не изменяются.
