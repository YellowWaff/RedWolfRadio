# Red Wolf Radio artwork

This directory contains the approved public branding assets for Red Wolf Radio:

- `red-wolf-radio-primary-logo-transparent.png` is the full logo for project pages and release material.
- `red-wolf-radio-launcher-icon-64.png` through `red-wolf-radio-launcher-icon-512.png` are square launcher and listing sizes.
- The repository-root `previewimage.png` is the canonical Steam Workshop and Republic Mod Loader preview.

The character is Sangie. The artwork is included and distributed with the rights holder's permission for Red Wolf Radio. These image files are not licensed under the repository's GPL-3.0-only source-code license, and that license does not grant permission to reuse the artwork outside Red Wolf Radio.

Alternate concepts, source references, promotional pinups, and working files are intentionally excluded from the public source package.
