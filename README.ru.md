# Red Wolf Radio

Своя музыка для **Workers & Resources: Soviet Republic** через **Republic Mod Loader (RML)**. Оригинальные файлы игры не изменяются.

**Red Wolf Radio 1.0.0** добавляет воспроизведение внешних XWMA и компактный плеер с кнопками-значками и автоматическим обновлением названия трека. Поддерживаемая конфигурация: Windows x64, WRSR 1.1.1.9, RML 1.0.1. При несовпадении проверенных файлов игры или загрузчика плагин не устанавливает перехватчики.

## Установка и музыка

1. Подпишитесь на [Red Wolf Radio](https://steamcommunity.com/sharedfiles/filedetails/?id=3805202523) и [Republic Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3787969749).
2. Включите Red Wolf Radio в RML и запускайте игру через RML. Одновременно должна быть включена только одна копия плагина; отключите локальные копии перед включением версии из Workshop.
3. Добавьте WAV, MP3, FLAC или XWMA в свою папку «Музыка» либо укажите другую папку в `RedWolfRadio.ini`. Папки сканируются при каждом запуске, включая вложенные папки. Обложки альбомов и другие неподдерживаемые файлы игнорируются.

Плагин передаёт **RIFF XWMA/WMAudio2** игровому загрузчику без преобразования в WAV. Поддерживаются один или два канала, частота 8–48 кГц и 16-битные декодированные отсчёты. Короткий путь с символами ASCII используется напрямую; для длинного пути или кириллицы в имени создаётся побайтовая копия `.xwma` в кэше. Сжатый звук декодирует сама игра при воспроизведении. Повреждённые файлы и другие профили WMA пропускаются с записью в журнале.

Чтобы использовать музыку из другого предмета Workshop, скопируйте его `.xwma` в выбранную папку. Плагин не скачивает музыку автоматически и не изменяет исходный предмет Workshop. WAV, MP3 и FLAC преобразуются в совместимые WAV-файлы в общем кэше.

Для окна плеера нужны также сценарий, значок и запись сценария в метаданных предмета. Копирование только DLL и INI обеспечивает воспроизведение и сочетания клавиш, но не добавляет пункт в меню сценариев. Для локальной установки используйте полный пакет Workshop и указания в `DISTRIBUTION.md`: сохраните метаданные своего предмета и добавьте запись сценария перед `$END`. Простая распаковка архива не регистрирует сценарий в игре.

## Настройки

Откройте `RedWolfRadio.ini` через **Open settings** в RML. Имена разделов, ключей и значения команд остаются английскими; комментарии в файле даны на двух языках. Изменения применяются после перезапуска игры.

```ini
[Sources]
ExternalEnabled=true
ExternalPath=%USERPROFILE%\Music
ExternalRecursive=true
PluginLocalEnabled=false
PluginLocalRecursive=true

[Cache]
MaxSizeMiB=4096
PrefetchTracks=5
HistoryTracks=3

[Hotkeys]
Enabled=true
Next=Ctrl+Shift+Right
Previous=Ctrl+Shift+Left
PlayPause=Ctrl+Shift+Down

[Display]
ShowTrackName=false
NativeSongPopup=true
Language=ru

[Originals]
Mode=all
ExcludedIds=
```

- `%USERPROFILE%` заменяется папкой текущего пользователя. Пустой `ExternalPath` использует системную папку «Музыка», включая перенаправление в OneDrive.
- `PluginLocalEnabled=true` включает папку `Music` рядом с DLL.
- `NativeSongPopup=true` включает окно плеера, доступное через меню сценариев. Оно не открывается автоматически. `false` отключает плеер после перезапуска игры.
- `ShowTrackName=true` отдельно включает пятисекундное уведомление с исходным именем файла без расширения. По умолчанию уведомление отключено (`false`). Длинные имена сокращаются на экране; имена файлов кэша не отображаются.
- `Language=ru` включает русские подсказки при наведении на кнопки, сообщение в пустом плеере и подпись уведомления; `en` — английские. Само имя трека не переводится. Кириллица и знак `%` проверены в игре.
- `Mode=all` сохраняет все оригинальные треки; `none` отключает их; `selected` исключает только ID из `ExcludedIds`. ID вида `original:…` можно найти в журнале RML по строкам `Original ID:`; несколько ID разделяются запятыми.

Существующий INI и явно заданные настройки не перезаписываются. Отсутствующие параметры используют значения `NativeSongPopup=true`, `ShowTrackName=false` и `Language=en`. Если в старом INI уже записано `ShowTrackName=true`, уведомление останется включённым. Измените или добавьте нужные параметры в существующем разделе `[Display]`; не создавайте второй такой же раздел. Для русских подписей укажите `Language=ru`. Сохраните файл в UTF-8; не переводите ключи и названия сочетаний клавиш.

## Управление

| Сочетание по умолчанию | Действие |
|---|---|
| Ctrl + Shift + → | Следующий трек |
| Ctrl + Shift + ← | Начать текущий трек заново; повторное нажатие в течение секунды — предыдущий |
| Ctrl + Shift + ↓ | Пауза / продолжить с того же места |

Сочетания работают в загруженной республике при активном окне игры. Можно переключать треки во время паузы: воспроизведение продолжится после снятия паузы. `None` отключает отдельное сочетание. Недопустимые и одинаковые сочетания отключаются с записью в журнале.

## Окно плеера

В загруженной республике откройте **Настройки → Другое → Сценарии** (значок **0101**; в английском интерфейсе **Settings → Other → Scripts**), выберите **Red Wolf Radio** и нажмите зелёную галочку. Компактное окно размером 360×128 единиц интерфейса масштабируется вместе с игрой, остаётся открытым и само обновляет название трека. На четырёх кнопках показаны значки; при наведении название действия появляется в красной строке заголовка. Значок «Играть/Пауза» меняется вместе с состоянием воспроизведения. Длинные имена занимают до двух строк, затем сокращаются многоточием. Повторный запуск этого пункта не создаёт второе окно.

| Кнопка-значок, слева направо | Действие |
|---|---|
| Предыдущая | Сразу перейти к предыдущему треку в истории. В начале истории — начать самый ранний доступный трек заново. |
| Сначала | Начать текущий трек заново. |
| Играть / Пауза | Продолжить или приостановить воспроизведение с сохранением позиции. |
| Следующая | Перейти вперёд по истории, затем продолжить плейлист. |

Кнопка **«Предыдущая»** сразу переключает трек. Сочетание **Ctrl + Shift + ←** сохраняет прежнее поведение: первое нажатие начинает текущий трек заново, быстрое второе — возвращает к предыдущему. Переключение трека и кнопка «Сначала» сохраняют паузу до нажатия «Играть». Сочетания клавиш также обновляют открытое окно.

Перетаскивайте окно за красную строку заголовка. Кнопка **X** закрывает окно, не останавливая музыку. При следующем открытии оно снова появляется в центре: положение не сохраняется между открытиями и сеансами игры. Другие окна поверх плеера блокируют нажатия на закрытые ими кнопки. Язык подсказок выбирается параметром `Display.Language`; значки, название Red Wolf Radio и пункт сценария одинаковы для обоих языков.

## Кэш и диагностика

По умолчанию заранее готовятся пять следующих треков; три предыдущих защищены от удаления. История хранит до 64 записей за сеанс. Общий кэш находится в `%LOCALAPPDATA%\RedWolfRadio`; лимит 4096 МиБ (4 ГиБ) является мягким: активный, следующие и защищённые предыдущие треки могут его превысить. `MaxSizeMiB=0` отключает ограничение. Ненужные старые файлы удаляются первыми. При закрытой игре кэш можно очистить; исходная музыка останется нетронутой.

Путь, передаваемый игровому загрузчику, должен помещаться в его 256-байтный буфер. Если Windows предоставляет короткое имя пути с символами ASCII, плагин использует его. Путь к кэшу с кириллицей без подходящего короткого имени может привести к отказу подготовки с сообщением в журнале. Исходные имена файлов с кириллицей поддерживаются через копию в подходящей папке кэша.

Журналы запуска находятся в RML, подробные музыкальные журналы — в `RedWolfRadio-logs` рядом с DLL. При сообщении о проблеме приложите версию игры, RML и плагина, настройки без личных путей и соответствующий журнал; музыкальные файлы публиковать не нужно.

Обычное обновление Workshop сохраняет пользовательский INI в проверенном сценарии 0.9.0. Перед принудительным обновлением RML, отменой подписки или ручной заменой сохраните INI и локальную музыку за пределами папок игры и Workshop. Если Steam считает закрытую игру запущенной, закройте также редактор настроек, открытый из RML.
